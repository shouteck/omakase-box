# PF44: an imported listing approved by a comment on its GitHub issue

## Outcome
Anyone signed in can import an existing issue as a bounty (`POST /api/import`). The import stays `pending` until the issue's author, or someone GitHub calls `OWNER` or `COLLABORATOR`, posts the exact comment `omakase approve <id> $<amount>` on the issue. The owner does not sign in to the board to approve. While the import is pending, it is left out of the open list, promises no payout, and accepts no payment or payment record. The approving comment's URL is stored as proof, and its author becomes the poster. GitHub OAuth is still needed to list directly (`/api/list`, unchanged) and to manage the listing later.
