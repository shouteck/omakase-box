# RC04 — Omakase Box agent release candidate 0.4.0

## Scope

Integrate #40 (demo-board CLI posts) and #26 (squash/rebase merge recognition). Fix launch-blocking instructions for setup, solving, posting approval, reward setup, pushing and payment authorization. Keep npm, Agent Skill and MCP on the same release version. #39 owns the expanded agent walkthrough and manual solver PR base/closing instructions.

## Done when

- Run `node scripts/verify.mjs --full test:box-bounty test:kitchen test:platform`.
- Pack with `node packages/box-cli/pack.mjs --out <artifact-directory>`; compare the CLI-installed skill with the skill repo bytes, package both artifacts with checksums, and read Stripe webhook readiness without making writes.
- After a separately approved release, run `node scripts/check-release-versions.mjs` against npm latest, the public skill and the hosted MCP. It requires all three to report the candidate version.
