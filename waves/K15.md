A kitchen wave: it cooks only when named. **It creates a new public repository on the owner's GitHub account, so its pre-cook card waits for the owner's "go"** (the owner approved the idea on 13 October 2026; the go covers the exact name and what is put in it).

## Why

BT10's real journey ran on the kitchen's own repository, where the rulebook rightly reserves public posts and changes to instruction files for the owner. So a test needed the owner's go, the owner's choice of how agents learn of a bounty, and, by the head chef's mistake, the owner's answer to a comprehension question. A test that needs the owner is testing in the wrong place.

## Outcome

The kitchen has one throwaway public repository where it may post, solve, merge, close, switch the hook on and edit instruction files as often as a wave needs, with nobody asked. The owner is involved once: the go for this wave. No later wave's real run touches `shouteck/omakase-box` or asks the owner anything.

## Scope

- Write: `kitchen/**` (a page on the sandbox and how a wave uses it), `templates/wave.md` (one line), `docs/box-v4/KITCHEN.md` ("Verification", a short paragraph), `tests/kitchen/**`. On GitHub: the new repository only.
- Read for context: `waves/BT10.md` Result (what a real journey needs and what it left behind); `waves/BT9.md` Result (the hook's missing live-host proof); AGENTS.md "Who decides what".
- Do not touch: product code; `shouteck/omakase-box` on GitHub beyond reading; the owner's settings for any repository but the sandbox; this repository's instruction files or hooks.

**How later waves use it**

- A page in `kitchen/` says: real-GitHub steps run in the sandbox; what a wave may do there without asking (everything the tool does, inside that repository); what still goes to the owner (anything on another repository, spending, a new destination, real money); and how a wave cleans up (close what it opened, list what it leaves).
- `templates/wave.md` gains one line: a wave with a real-GitHub step names the sandbox, and a step that needs the owner as a test subject is not written.
- A test in `tests/kitchen/` fails if a wave file under `waves/` written after this one asks for a real post on `shouteck/omakase-box`.

**Cases that must fail:** the tool allowed on the sandbox still refuses a private repository and a never-ship path there; a wave pointing its real step at the working repository is caught by the test above.
