# A1: a neutral agreement and one declared-program launch rule

Milestone: A · Station: packaging · Base: `0415a31` · Branch: `wave/A1` · Run limit: A1 only; stop and report if the outcome cannot be met within this scope.

## Outcome

An owner can declare setup and guard/outcome checks for arbitrary programs, plus what a solver needs installed, without a required Node/pnpm/TypeScript/Vitest toolchain. Every declared program is checked for availability before commands execute. One documented operating-system launch rule handles Windows command-file shims without tool-specific dispatch. Existing active agreements and callers migrate together; the old agreement format and fixed command-tool enum are removed.
