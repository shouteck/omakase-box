## Outcome

An owner allows their agents to solve, once. From then on the agent runs `box bounty discover` on its own schedule. It gets each new bounty that passes its filter once, with the facts to judge it, and nothing else.

## Scope

- Write: `packages/box-bounty/` (settings, `allow`, `config`, a new `discover`, help and errors), `tests/box/bounty/`.
- Do not touch: the board (beyond reading it), payments, `take` and `submit` (PF25, PF26).

## Build

1. **Two kinds of settings, kept apart** (D-2026-11-03-solver-in-the-tool: tuning in lives in the solver):
   - **The owner's, in the owner's own settings, through `allow` and `config`.** These are the switch (solving off by default, ask each time before taking, or allowed) and the owner's guard rails, which the agent cannot loosen: a floor on the reward, pays on merge only, repositories never to take from. No new owner command. Off means `discover` says how to ask the owner and does nothing else.
   - **The agent's own,** given as `discover`'s options and kept in the tool's local record with the bookmark: languages, its own minimum above the owner's floor. The agent changes them as it likes, inside the owner's guard rails.
2. **`discover`:**
   - reads the board's "new since" from the bookmark kept in the tool's local record;
   - applies the filter;
   - prints each bounty with its facts, money first: pays on merge, reward, attempts in progress, the owner's record and time to decide, size, age;
   - advances the bookmark only after printing;
   - `--json` gives one complete document.

   Poster text is marked as the poster's, and the board's line "the board has not read or run this repository's code" is carried.
3. **The cadence:** `discover` states the board's 15-minute floor and how to schedule it on common hosts. It schedules nothing itself.

## Done when

- `node scripts/verify.mjs test:box-bounty test:platform test:kitchen` exits 0 on the final commit.
- **The switch:** with solving off, `discover` reads nothing from the board and says how to ask, and a test proves no request is made.
- **The bookmark:** each bounty appears once across two runs and a restart. The bookmark survives a crash between printing and saving without skipping, and the stated duplicate rule is tested.
- **The filter:** each part is tested against a stand-in board, showing first that the row it removes is really there.
- **Guard rails hold:** an agent's own option below the owner's floor, or naming a repository the owner excluded, is refused by name and changes nothing.
- **Help and errors:** every new refusal names itself and exits 3, and `--help` works.
