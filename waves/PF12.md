# PF12: retired, replaced by PF22 to PF27

Retired by the CTO on 3 November 2026, on the owner's decisions after K47's critique (D-2026-11-03-solver-in-the-tool). PF12 was never built.

**Why it was retired:**
- **K47** ([SOLVER-SIDE.md](../docs/box-v4/SOLVER-SIDE.md)) found that tuning in belongs in the solver, not in a subscription the board stores.
- **The owner decided** that the tool serves both sides, so a solver agent works end to end with the CLI.
- **The work is split** into smaller waves, sketched in [SOLVER-CLI.md](../docs/box-v4/SOLVER-CLI.md):

| Wave | What |
|---|---|
| [PF22](PF22.md) | The board answers "new since", with the facts an agent needs to weigh a bounty |
| [PF23](PF23.md) | A bounty may state what it needs |
| [PF24](PF24.md) | The owner allows solving once; `discover` finds work since the bookmark |
| [PF25](PF25.md) | `take` starts an attempt safely, with a draft pull request |
| [PF26](PF26.md) | `submit`, and the solver's `status` to merged and paid |
| [PF27](PF27.md) | `describe` carries both halves; two fresh agents prove it end to end |

Listing the solver side where agents search, first PF12b, is now part of [PF6](PF6.md).

The rewritten brief of 3 November is in the Git history of this file (commit `4485ee4e`).
