## Original contract

- Age and latest-activity facts appear in text and JSON for each open bounty; a draft uses `createdAt`, a posted bounty uses its `posted` event, and latest activity is the newest valid posted/attempt collection time.
- A posted bounty inactive for 14 days gets one once-only line, at most three per command, oldest first. Records, shared chains, stage transitions, the hook line and instructions remain unchanged.
- `status --json` promises ISO 8601 age facts; invalid or unknown source times are explicit null/unavailable facts, never `NaN`, a non-ISO echo or an invented substitute.
- The original tests, acceptance bar, UX lens, worker notes and stale deadline are superseded by `waves/BT35-resume.md`; the full pre-merge file remains in Git history on `wave/BT35`.
