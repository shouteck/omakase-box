Detailed for a cook without deep reasoning: the target layout is below, function by function, and the method is BT25's, which went cleanly. **A pure move: no behaviour changes, no test expectations change.**

## Why

`packages/box-bounty/github.ts` is now the largest file (about 1,680 lines) and does at least five jobs: the `gh` client and response checks, the publication plan, posting, collecting solutions, and closing up. It is in every one of the three import cycles BT25 left:

- `github.ts ↔ answer.ts`: `github.ts` imports `NOTHING_RUN`, `emitMergeNotice`, `quoteForeign`, `showPath` from `answer.ts`; `answer.ts` imports `resolveAttempt`, `syncGitHubDecision`.
- `github.ts ↔ gate.ts`: `gate.ts` imports `planGitHub`, `shownOfPlan`; `github.ts` imports `ownerGate`, `allowedByFor`, `sameShown`, `waitForOwner`.
- `github.ts → answer.ts → gate.ts → github.ts`.

## Outcome

`github.ts`'s jobs live in five modules, `packages/box-bounty/` has **no import cycle at all**, and every public name stays importable from `index.ts` and from `github.ts` as before.

## Scope

- Write: `packages/box-bounty/**`; test files' import lines only, and only if a test imported a private helper that moved (a public name stays reachable from `github.ts`).
- Do not touch: any function body beyond an import path; any test expectation; any output.
