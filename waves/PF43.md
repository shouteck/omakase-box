**Brief.** Written by the CTO on 10 November 2026 from [K56](K56.md), and rewritten the same day so that any model can cook it: the design is already drawn and the cause of the fault is already found. The front page is the site's best page and its direction stays. Three things keep it from finished:

- **On a phone the hero's picture first appears as a tall empty black box.**
- **A section can be invisible while it waits to animate.**
- **The install line is a click away.** Developer tools put the command itself in the hero with a copy button; ours is behind "Get started".

**The cause of the first two, read in the code on 10 November:** it is CSS, not a script. In `packages/box-platform/app/globals.css` the keyframes `rise` start at `opacity: 0`, and both `.story` and `.arrive` use `animation-fill-mode: both`. So each line of the picture is invisible until its delay (`--at`, up to 3.8 seconds) has passed, and each `.arrive` section is invisible until it scrolls into view. A screenshot, a slow phone, or a reader that never scrolls sees nothing there.

**The picture to build to** is `docs/box-v4/design/front.html`. Read the section "The front page" in `docs/box-v4/design/README.md`, run `node docs/box-v4/design/shoot.mjs --before`, and look at `front-a-*` and `front-b-*` in `shots/after/` beside `shots/before/front-*`.
