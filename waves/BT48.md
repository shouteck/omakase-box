# BT48: never-ship matches what a path looks like, not only how it is spelled

Milestone: BT · Station: packaging · Base: `master at dispatch` · Branch: `wave/BT48` · Timebox: 180 minutes; at expiry, report partial findings and stop
Owner decisions: none
Horizon: short

**Brief.** Written by the CTO on 21 October 2026 from the engineering review. The hard stop is the product's core promise; this closes a spelling gap in it. **No new rules and no new dependency:** the same rule words, matched after normalisation and a small confusables fold.

**Refined by the CTO on 22 October 2026** (owner's request to review the nine engineering-review briefs): code claims checked against master `24bb6b8`; changes are listed under "CTO refinement" at the end of this brief.

## Why

`never-ship.ts` decides on `path.toLowerCase()` and segment containment (lines 95, 146, 252). A path that is visually the excluded one but written with a look-alike character passes: Cyrillic `е` in `sеcrets/`, or in `.\u0435nv`. Fullwidth `ｓｅｃｒｅｔｓ` passes too, and NFD/NFC differences matter on APFS. The owner's files are not attacker-named, but an agent acting on a stranger's task can create such a path, and the boundary is supposed to be the thing that still holds.

## Outcome

A path whose normalised, confusable-folded skeleton is an excluded path is refused exactly as the plain spelling is. The message shows the path as it was found, quoted, and names the rule.

## The change

1. In `never-ship.ts`, add one function that returns the matching skeleton of a path: NFKC-normalise, lower-case, then fold a small, named confusables table to ASCII. Keep the table to the characters that appear in the rule words and credential names; comment that it is deliberately small.
2. Match every rule (`dot-git`, `secrets-dir`, `runtime-dir`, `dot-box`, credential names, owner entries) against the skeleton, not the raw string. The canonical path returned and shown stays the real one; only matching changes.
3. Do not widen a rule: `secrets-guide.md` stays refused (the segment contains `secrets`), `secret-sauce.md` stays allowed, `.env` stays refused, `.env.example` stays refused (corrected at kickoff, see below).
4. No new package. A table plus tests is enough.

## Done when

- Tests that must fail first: `sеcrets/` (Cyrillic е), `.\u0435nv`, fullwidth `ｓｅｃｒｅｔｓ`, and an NFD spelling of a refused name are each refused with the right rule named.
- A property test generates, for every rule word, a set of variants (case, NFKC width, the table's confusables) and asserts each is refused; a plain allowed path (`docs/secret-sauce.md`, `secretary/minutes.txt`) stays allowed in the same run.
- A test proves the guard bites: remove the fold and the property test goes red.
- The existing never-ship suite is unchanged and green.

## Notes

- NFKC alone does not fold Cyrillic to Latin; the table is the part that matters. Do not claim full Unicode confusables coverage — describe it as the named set.
- Do not change what is printed as the path; `quoteForeign` already escapes it.
- A false positive is safer than a miss, but record any new one in the Result.
- Keep the function pure and put it where both the rule list and the owner entries use it.
