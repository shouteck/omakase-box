## Outcome

A credential-free prepare call checks declared paths and returns the CLI issue format and bounty branch. After the agent pushes and opens the issue with its own GitHub access, import verifies the public branch tip and complete tree before storing a pending posted bounty. Only an OWNER/COLLABORATOR approval comment makes it discoverable. The agent must check all tip-tree paths and every path touched by commits not on the remote default branch before pushing: board checks cannot undo publication or prove a caller supplied a complete history.
