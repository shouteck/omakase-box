# K51b: a map of what every test defends (K51, taken further)

Milestone: K (kitchen) · Station: evidence · Base: `master at dispatch` · Branch: `wave/K51b` · Timebox: 300 minutes; at expiry, report partial findings and stop
Owner decisions: the owner asked on 12 November 2026 for "a more thorough examination of the tests" after K51 stopped at its cut-off, and chose "read and map".
Horizon: long: the plan is in this file.

**Brief.** K51 protected files by keyword (`never-ship`, ...) and said four of the five slowest "guard a hard stop"; that was a heuristic reported as a fact. This wave replaces it with a map built from what the tests assert. No product code and no test changes; nothing is removed unless the K51 proof method (break the guarantee, see another test go red) is then run, which this wave does not do.

## Outcome

`kitchen/reviews/K51b-test-map.md`: for every test (not file) what it asserts: the refusal names it expects and the CONTRACTS guarantees it proves; which tests are the guard of each hard stop (CONTRACTS labels them "hard stop", K30's proof map names the tests); for every file the share of its tests that touch a hard stop; the guarantees and refusal names proven by exactly one test; and, if the pilot shows it can be measured, the code each file alone reaches. K51's wording corrected.

## Plan

1. Extract every test from the TypeScript source (the compiler's syntax tree, not a text search): file, describe path, title, lines, the refusal names its body asserts (the 134 names CONTRACTS lists), the CONTRACTS guarantee ids it names.
2. Hard stops: take the guarantees CONTRACTS labels "hard stop" and the tests K30's map names for each; add every test that asserts one of their refusal names; read each such test's title and assertion before calling it a guard.
3. Per file: tests, hard-stop tests, share. Per refusal name and guarantee: how many tests prove it; those with one are the unique proofs.
4. Pilot per-file code coverage on three files (Node's own `NODE_V8_COVERAGE`, no new dependency); run it on all files only if the pilot's overhead and meaning are acceptable. If not, say so and stop.
5. Write the map; correct K51's wording (STATUS, review, Result); kitchen checks; merge.

## Done when
