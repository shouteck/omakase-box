## 1. The flaky `bt39` test

The assertion "an unchanged pull-request set costs no per-request file calls" failed on documents-only `bf2c815` and passed on identical code at `aafaf67`. It is timing-dependent on the "new" versus "seen since" transition.

**Fix:** make the transition explicit in the test — inject or fix the clock, or call the internal function twice on a record whose state is controlled — and assert the invariant, not the elapsed order. Do not loosen the assertion. **Done when** it passes 20 consecutive local runs and still fails when the caching is removed.

## 2. `status --comments` drops the poster's own account

Backlog BT10 confirmed live: comments from the same account as the poster are silently omitted, so a solver replying under that account looks like silence.

**Fix:** list comments from any account, labelling each by its author as the tool already does; keep "written by others, not by the tool" true by marking the tool's own comments instead of excluding the poster's account. **Done when** a fixture with a comment from the poster's account shows it, and a tool-written comment is still distinguishable.

## 3. `kitchen-stats` reads a large graph with the default buffer

`commitGraph` uses `spawnSync` with the default 1 MiB buffer and returns null on any failure (K15-ci). It is at about 138 KB today.

**Fix:** an explicit buffer sized for the graph, and a named failure instead of null. **Done when** a unit test feeds a synthetic oversized output and gets the named failure, not a silent null.

## 4. The Node floor says one thing and runs another

Checked on master: `NODE_MINIMUM = '22.13.0'` (`packages/box-cli/src/node-check.ts:15`), `pack.mjs` reads the manifest's `engines` from it, the CI install job pins `22.13.0`, and the README says 22.13. They agree today. (`.node-version` is the development toolchain, 24.11.0, not the floor.)

**Fix:** pin the agreement so it cannot drift: one test reads the check's constant, the packed manifest's `engines`, the CI install job's pin and the README line, and asserts they agree, and that the `node-too-old` refusal names the same version. **Done when** that test passes and bites (change one value in a scratch copy and it fails).
