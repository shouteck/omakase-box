## The Windows Check

A museum's kiosk installer fails in a Windows folder named `Museum Kiosk`. The agent preparing opening day has no Windows machine to test on. We follow the handoff through Omakase, from the poster's preview to the outside solver's pull request, then watch the human open the kiosk. The cut demonstrates the workflow as it exists today; the agent-only economy appears separately as a future vision.

**45 seconds**, silent-first, 1920×1080 at 30 fps, H.264 MP4. Warm unbleached paper `#f5f2ea`, hand-drawn ink `#1d1b17`, one ink-blue accent `#234a7d`, Inter throughout. Use screen-sized lettering and one focal point per shot. The parcel and the path are the film's only recurring graphics; no stock art, copied launch branding or simulated product chrome.

## Product and capture rules

- **One Omakase, three layers.** The recommended setup writes the Agent Skill for supported agents and installs the CLI if needed; start a new agent session after setup. The CLI posts and solves in a local checkout. MCP is read-only discovery, available without the CLI or sign-in. The single CTA is a way in, not the only way to discover Omakase. Agent Skill catalogs, MCP registries, skills.sh, ClawHub, Glama and optional Monid distribution are planned and not submitted; there is no Monid partnership. Do not show any as live listings.
- **Setup is not authorization.** “One line, and your agent can post and solve work” skips prerequisites. Use the narrower end-card promise above; optional owner wording: “One line gives your agent Omakase. Posting and solving need your OK.” In the capture, set up the public repo, GitHub credentials and owner rules off camera: `omakase-box allow` with `--ask` for the poster's per-action post and merge approvals, and separate solving permission for the solver. Humans approve listings and payments today. The poster reviews the returned work before requesting merge approval. The receipt illustrates a distinct manual owner payment, not an automatic payout or proof of a real paid job.
- **Capture placeholders are not product copy.** Replace the indicated inserts verbatim from an owner-approved sandbox recording, with no money moved. Use the real CLI and MCP against an offline board and GitHub stand-in for the complete sample handoff; keep the raw takes and show no made-up tool output. A $0 bounty from the [public kitchen sandbox](../kitchen/sandbox.md) never appears on the live board, so MCP discovery and CLI `take`/`submit` must come from the local fixture; do not imply they found or took a live $0 bounty. If separately approved, a $0 public sandbox recording can supply a public issue insert labeled as such. Show only intact, cleared lines: no credentials, personal paths, private data or amounts. Omit an insert rather than shrinking it to illegibility.
- **The destination is not shipped.** Only the “Where this goes · Future vision” shot depicts agents settling work themselves. The diagram does not show live volume, waiting solvers or an autonomous settlement feature. The present-day demo ends with human approval and manual payment.
