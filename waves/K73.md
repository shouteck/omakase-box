Milestone: K (kitchen) · Station: evidence · Branch: `wave/K73` · Timebox: 240 minutes; at expiry, report where it is and stop
Owner decisions: on 13 November 2026 the owner said nobody but the owner and the sandbox ever used a version before 0.2.0, and "Yes, go" to removing three groups of retired-shape handling, tests and readers together. Playbook: refactoring ([principle-subtract-before-you-add](../.devin/plugins/box-pstack/skills/principle-subtract-before-you-add/SKILL.md), [principle-migrate-callers-then-delete-legacy-apis](../.devin/plugins/box-pstack/skills/principle-migrate-callers-then-delete-legacy-apis/SKILL.md), principle-prove-it-works).

## Scope (read from the code on 13 November 2026)

**Group 1: the old shared-record name `refs/box-bounty/<id>`** (chain written before BT58). Remove in `packages/box-bounty/chain.ts`: `CHAIN_NS_OLD`, `CHAIN_REMOTE_NS_OLD`, `LEGACY_KEYS`, `nsKey`, `knownLayout`, `isOldChain`, `settleLayout`, the `lists.old` branch in `resolveTips` and the old pair in `TipLists`, the second refspec of the fetch in `syncChains`, the two extra patterns of the `for-each-ref` in `adoptAndImport`; `chainRef` and `remoteRef` return the one name. Remove the two exports in `index.ts`. After this nothing reads, fetches or writes a ref under `refs/box-bounty/<id>`: the name Git resolves before a branch (BT58).
**Group 2: the `snapshot:` line in a merge message** (a record from before BT24). `answer.ts` line 263 and its comment. And in `record.ts` `dropDurabilityRefs`: the read of `refs/box-bounty/<id>` and its delete (it exists only to tell an old snapshot pin from an old chain), two Git starts fewer on every end stage.
**Group 3: stored text that names removed commands.** The two rewriting blocks in `record.ts` `asRecord` (the `github.pending` block and the `outside.answers` block, from "BT7c: pending text is tool-written" to the closing brace of the second).

**Not touched, and why (stated so the Result can list them):** the board (`packages/box-platform` reads the old name as a fallback; a separate product surface, deployed by the owner), the `snapshot` field's type and `baseCommitOf`'s fallback and `post.ts`'s legacy post path (the old-draft path has its own named refusals), the GitHub snapshot publication code in `gh.ts`, the refusals `legacy-delivery-retired` and `legacy-task-unavailable`, `noteSource: 'legacy'`. Each is another reader of a retired shape; each is listed for the owner in the Result.
