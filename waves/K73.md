## Scope (read from the code on 13 November 2026)

**Group 1: the old shared-record name `refs/box-bounty/<id>`** (chain written before BT58). **Group 2: the `snapshot:` line in a merge message** (a record from before BT24). `answer.ts` line 263 and its comment. And in `record.ts` `dropDurabilityRefs`: the read of `refs/box-bounty/<id>` and its delete (it exists only to tell an old snapshot pin from an old chain), two Git starts fewer on every end stage.
**Group 3: stored text that names removed commands.** The two rewriting blocks in `record.ts` `asRecord` (the `github.pending` block and the `outside.answers` block, from "BT7c: pending text is tool-written" to the closing brace of the second).

Each is another reader of a retired shape; each is listed for the owner in the Result.
