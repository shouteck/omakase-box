# A2: explicit files, proven outside the owner repository

Milestone: A · Station: packaging · Base: `5c2bd82` · Branch: `wave/A2` · Run limit: A2 only.

## Outcome

An owner lists the files a Box contains without requiring TypeScript import traversal. Export copies their bytes and proves the selection with declared checks outside the checkout. TypeScript traversal remains an optional proposal helper, not silent authority to add files. Selected project dependency files travel unchanged. Each outcome check is compared with the same command on the untouched full repository so a missing file cannot masquerade as the requested defect.
