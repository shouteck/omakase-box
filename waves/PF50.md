# PF50: /llms.txt on the board

Milestone: platform · Station: packaging · Base: `master` · Branch: `devin/1795362421-llms-txt`

## Outcome

`GET /llms.txt` answers an [llms.txt](https://llmstxt.org/) index of the board's machine interface: the feed, one
bounty, the MCP server, numbers, RSS, and the CLI's solve and post steps, with links to `/agents/` and `/how/`. Part
of the 0.4.1 polish list. SOLVER-DISTRIBUTION section 1 keeps llms.txt only if it costs nothing: it is one Worker route
with no store read, and it repeats only what `/agents/` and the README already say. No page copy changes, no deploy,
no release.

## Done when

- `/llms.txt` answers 200 `text/plain` with the closed non-page policy, in the llms.txt shape (title, summary, sections).
- Every board link in it is absolute on the host that was asked and answers 200 (the MCP one to a `tools/list` POST).
- It names every MCP tool the server lists and the CLI's solve and post steps.

## Changed expectations

None.

## Result

- `src/llms.ts` builds the text from the request's origin, so the local board, the Worker URL and omakasebox.dev each
  point at themselves. Routed in `api.ts` beside `/rss.xml`; `secured()` adds the headers.
- `tests/platform/llms.test.ts` (4 tests). Platform suite on Devin Linux: 25 files, 520 tests passed.
