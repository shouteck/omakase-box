## Steps, in order

1. Pre-register prompts, arm allocation and observations in Plan before opening sessions. Use three matched task pairs (six seats): a queue task that seat cannot finish but an outside solver could, with and without a lease/give-up trigger. Add one matched control pair (two seats) where declining is correct. Same tool wording, authority, task budget and obstacles in both arms; only trigger differs. Shuffle order and run one at a time.
2. Use fresh sessions in isolated `kitchen-K74-*` scratch folders, never subagents or sessions primed by repository AGENTS.md (`kitchen/roles/cto.md`). Supply the shipped instruction text, a stand-in queue and a $0 local create/post recorder; no real posting. Use BT70's lease if merged, otherwise an explicitly labelled fixture lease, and record which. Neither arm says to use the bounty tool or requires posting.
3. Pilot the fixtures, not a participant: prove the wall is real for the seat, removable by an outside solver, and that the control should decline. Prove local recording distinguishes describe/create/post and that no command can reach real GitHub. Any real GitHub need stops for `kitchen/sandbox.md` rules; never post outside that sandbox or invent a real reward.
4. Run all eight seats. Record each session's id, arm, task, trigger reached/not reached, ran `describe`, considered hand-off (quoted evidence), created, posted, declined and missing/failed observations. An interrupted session remains in the table; a retry gets its own row. “Considered” without log evidence is unknown, not no.
5. Compare raw counts separately by arm and controls against GTM.md's 1 of 5 defensible uninstructed hand-offs (and six correct declines). Do not pool denominators, infer a rate or claim causality from eight seats. Report trigger reachability, task/model/fixture limits and whether the behavior supports the proposed pitch, with the evidence against it too.
6. Record a yes/no/insufficient-evidence decision for PF6's trigger wording. Only yes with observed unprompted posting and correctly declining controls licenses a qualified pitch; describe/considered alone is not posting. Link evidence from GTM.md; remove owned scratch resources.
