## Outcome

`node scripts/verify.mjs test:kitchen` is green on this host again, and stays green as more runs are recorded.

**What the CTO found on 11 October 2026.** `test:kitchen` failed twice in a row on master at `a7a2794`, a commit that changed only wave files and documents. One test fails: `tests/kitchen/kitchen-stats.test.ts`, "exits 1 naming the broken limit on a fabricated root, 0 on the real repo", on its 30-second timeout. Run by hand on the real repository, `node scripts/kitchen-stats.mjs` exits 0 and prints the right page, but takes 29.8 seconds. `.kitchen/runs` holds 252 run records and the page starts `git` for each (`scripts/kitchen-stats.mjs` lines 136 and 141), so its time grows with every verify run. The same suite passed earlier that day at `f9402d7` in 98 seconds, with four fewer records. The off-machine run is unaffected: a fresh checkout has no run records.

Nothing the page reports is wrong. It is slow, and the test's limit is where the slowness shows.
