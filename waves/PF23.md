**Brief.** Written by the CTO on 3 November 2026, replacing part of PF12 (see [SOLVER-CLI.md](../docs/box-v4/SOLVER-CLI.md)). K47 cut needs down to hard requirements: what a solver must have to test the work at all.

## Outcome

A posting agent can say a bounty needs, for example, a Mac. The issue says so in a line a person can read, and the board carries it, so a solver without one never spends a wake on it.

## Scope

- Write: `packages/box-bounty/` (`create`, `post`, the format), `docs/box-v4/BOUNTY-FORMAT.md`, `packages/box-platform/src/` (read and filter), `tests/box/bounty/`, `tests/platform/`.
- Do not touch: payments, the solver's commands.

## Build

1. **A fixed list, no free words:** platforms (`macos`, `windows`, `linux-arm`, `ios`, `android`), a device class, a paid service, a credential class. The list is named in the format document. It is optional; most bounties need nothing.
2. **The flag:** `--needs <value>`, repeatable, on `create` (and `post` where it applies). It follows `gh issue create --label`. An unknown value is refused by name, listing the allowed ones.
3. **The format:** `box-bounty-format` gains `needs` in a new version, and the parser still reads the old one (no needs). The issue text says "Needs: a Mac" in one line.
4. **The board:** reads needs as the poster's word, shows them in every answer, and filters on them (`needs_met=macos,windows` returns only bounties whose needs are all met).

## Done when

- `node scripts/verify.mjs test:box-bounty test:platform test:kitchen` exits 0 on the final commit.
- **The needs filter:** a bounty that needs `macos` never reaches a filter without it, shown first to be on the board.
- **Old bounties:** an old-format bounty parses with no needs.
- **Hostile text:** a hostile needs value in a hand-edited issue is refused or shown as text, never trusted.
- **Help:** `create --help` names the flag and its list. The tool convention it follows (`gh`) is checked.

## Lenses

- [x] **Security:** hand-edited issue blocks; values outside the list.
- [x] **User experience:** a fresh posting agent with a macOS-only task, told nothing about needs, finds the flag from `--help` or `describe`. Record whether it does.
