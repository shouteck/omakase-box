# D2.1: export a Box as a folder and prove it in a clean directory

Milestone: D2 · Station: packaging · Base: current master · Branch: `wave/D2.1` · Timebox: 5 hours

## Outcome

`node packages/box-cli/dist/... export <agreement.json> --repo <path> --out <dir>` (the exact CLI shape is the worker's to choose inside `packages/box-cli`) produces a plain folder for a supported request on `examples/private-shop`: `box.json` (outcome, base commit, read context, editable paths, checks, submission contract), the selected source, a generated lockfile + tool versions, and the evaluator checks. In a clean directory outside the repo with only Node, pnpm and Git, the folder installs and its declared checks run green. Export reports every import that leaves the selection as a named preparation gap and never reaches back into the owner repository.

## Design (decided by D2.1-proto)

Compiler-derived closure as the spine, agreement as the surface, closure check as the verifier — see the comparison in [D2.1-proto.md](D2.1-proto.md). Concretely:

- The agreement file declares: outcome text, base commit, editable paths (with package→owner path mapping), entrypoints/read-context roots, declared dependencies, excluded prefixes, checks, submission contract.
- Selection walks the TypeScript compiler's module resolution from the declared entrypoints/editable modules; every file pulled in is package source. Non-module editable inputs (e.g. `config/response-security.json`) come from the agreement's explicit editable mapping — the walk cannot find them.
- The derived set is then verified closed: every import resolves inside the set or to a declared dependency. A reachable-but-excluded file (e.g. `src/private/eligibility.ts`) is reported as a named preparation gap with its import chain — export fails, it never silently includes or falls back to the full repo.
- Type-only stubs (proto attempt C) are OUT of this wave — a real leak vector; may return later as an explicit opt-in for read-context only.
- The lockfile must be resolved in a staging directory OUTSIDE the repo workspace (pnpm will not write one for a non-member dir).
