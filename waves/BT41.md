## Why

A stranger's first contact is the README (`FIRST-FIVE-MINUTES.md`, packed as the package README), `box bounty help`, and the lines `allow` and `config` print. Parts of that text are out of date or missing, and one gap means an agent in a new project never learns the tool exists. Publishing waits on this wave.

## Outcome

A stranger who reads only the README and the tool's output can set it up so their agents use it, knows exactly what becomes public and where everything is kept, and every help line matches what the code does.
