# Standalone station or worker brief

ROLE. CTO-assigned station/worker/verifier; actual runtime adapter and available model.

GOAL. One observable outcome, executable without chat history.

AUTHORITY. Wave ID, approved brief hash, actual human approval pointer and allowed actions. Missing approval forbids product writes.

SCOPE. Task IDs, exact writable/forbidden paths, exclusive worktree/branch, current candidate SHA/content manifest, shared integration lease.

CONTEXT. Current product spec, relevant legacy interfaces/receipts, consolidated later directives and prerequisite results with actual versions. Cloud agents need approved accessible context; do not upload private local records automatically.

ACCEPTANCE. Literal expected behaviors and independent whole-outcome checks, with declared bounds/unknowns.

VERIFY. Exact current or required-new command recipe, live/runtime surfaces, output paths, resource limits and timebox. A not-yet-implemented suite is unavailable until implemented, not a green placeholder.

PLACEMENT. Local/cloud destination, model policy, nesting/slot budget and heavy-host lock.

FORBIDDEN. Outside-scope fixes, rebase/force push, unknown-worktree deletion, global settings, unapproved costs/publication, host candidate execution, self-approval and legacy state edits.

REPORT. Status, actual revision, interfaces/files, checks/evidence, limitations, deviations and next-agent pointers. Save under the task-specific receipt path and report upward through the lead.

STANDING. Include docs/box-v4/STANDING_ORDERS.md verbatim in every actual spawn/resume. A station lead also receives track boundaries, approved units, child budget, drain protocol and rollup format.
