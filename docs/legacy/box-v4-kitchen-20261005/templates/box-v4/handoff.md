Task/wave IDs and approved brief hash. Implementer/lead/verifier identities and runtime adapter. Exact candidate Git SHA or complete content digest manifest. Approved paths and actual changed files. Interfaces and predecessor evidence used. Environment/evaluator/tool versions and hashes.

Commands actually run, observed pass/fail/unavailable outcomes and saved evidence paths. Distinguish behavioral/runtime evidence, type checks, bounded models and operator assumptions. Current independent review decision and precise candidate binding. Integration destination/authority and actual result commit, if any. Known gaps and next-agent context.

State whether source changed after review. Never declare accepted or completed from an unverified receipt. The worker does not edit canonical acceptance state. The CTO records acceptance only after the independent gate and dependencies pass.
