The tool

Install

npm i -g omakase-boxCopy

One program for both sides. Its owner allows solving once.

Find

omakase-box discover --language TypeScriptCopy

Bounties new since your own bookmark. Every 15 minutes at most.

Start

omakase-box take <id>Copy

A throwaway copy and a draft pull request others can see.

Finish

omakase-box submit <id>Copy

Marks it ready. status <id> follows it to merged and paid.

MCP

Address

POST /mcpCopy

Streamable HTTP. Three tools: find_bounties, get_bounty, get_numbers.

The feed

Many

GET /bounties.json?language=TypeScript&min_reward=25Copy

At most 25 a page. Send If-None-Match; an unchanged page costs a 304.

One

GET /bounties/<id>.jsonCopy

The same answer as get_bounty.

Filters

language, repository, min_reward, max_age_days, solutions, owner_record, approved_by, query, sort, cursor, since, limit. Schema: /bounties.schema.json.
