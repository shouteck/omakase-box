# M2: Private requirements discovery

A PM can describe an outcome, inspect evidence and approve a resolved intent.

Read `docs/SPEC.md`, `docs/COMPOSITION.md`, `docs/ARCHITECTURE.md` and `docs/SECURITY.md` before implementing. These task cards are additive to their normative requirements. Normal execution requires accepted prerequisite handoffs. Sequential fallback may use checked implementations under START.md, while independent-review gates remain open.

The milestone passes when every task below has evidence and an independent accepted review. Sequential checked implementations alone do not complete the milestone. A mocked or unavailable mandatory runtime does not satisfy a real-runtime gate.

## M2.1: Private evidence and pinned snapshots

Role: `backend`. Prerequisites: M0.3, M1.3.

Write scope: `services/private-api/requests/**`, `services/private-api/snapshots/**`, `packages/planner/retrieval/**`, `tests/planner/evidence/**`. Shared changes require coordinator ownership.

### Implement

- Read-only snapshot importer with path/size rules and no execution of repository scripts.
- Text and PNG/JPEG evidence storage with opaque IDs, private provenance and bounded retrieval.

### Acceptance

- Repository import never executes lifecycle hooks or follows forbidden links.
- An evidence upload/path cannot expose host files or become executable HTML; contributors cannot fetch it.

### Verify

    pnpm test:planner -- --suite evidence
    pnpm test:security -- --suite evidence

Commands must really run or be recorded unavailable. Implement the relevant meaningful suite if this is its first owner; an empty script is not evidence.

### Handoff

Write a draft using `templates/handoff.md`, include `.execution/evidence/M2.1/`, exact revision, outcomes, failures and delivered interfaces. Reviewer checks the task and security boundary. Coordinator finalizes `.execution/handoffs/M2.1.md` and advances eligible successors. Do not assume previous chat history.

## M2.3: PM outcome review and decisions

Write scope: `apps/private-console/intake/**`, `apps/private-console/intents/**`, `services/private-api/intents/**`, `tests/e2e/intent/**`, `tests/contracts/intent/**`. Shared changes require coordinator ownership.

### Implement

- Goal/evidence form, facts/assumptions/unknowns presentation, before/after preview and internal decision UI.
- Owner approval of exact intent revision with private traceability.

### Acceptance

- A goal entered without technical detail produces a reviewable draft in demo mode.
- Required unresolved decisions block preparation; edit-after-approval invalidates affected downstream evidence.
