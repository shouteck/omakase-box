# M7: Private acceptance and payment obligations

A qualifying patch becomes an auditable candidate change and fair payable record.

Read `docs/SPEC.md`, `docs/COMPOSITION.md`, `docs/ARCHITECTURE.md` and `docs/SECURITY.md` before implementing. These task cards are additive to their normative requirements. Normal execution requires accepted prerequisite handoffs. Sequential fallback may use checked implementations under START.md, while independent-review gates remain open.

The milestone passes when every task below has evidence and an independent accepted review. Sequential checked implementations alone do not complete the milestone. A mocked or unavailable mandatory runtime does not satisfy a real-runtime gate.

## M7.1: Public checks and private integration pipeline

Role: `evaluation`. Prerequisites: M6.3, M5.3, M3.3, M5.2, M5.4.

Write scope: `packages/evaluation/pipeline/**`, `services/private-api/evaluations/**`, `tests/acceptance/integration/**`. Shared changes require coordinator ownership.

### Implement

- Frozen public and private VM jobs, template-specific patch mapping and evidence classification.
- Private candidate diff produced as data against exact base; no merge/deploy.
- Map all units/shared interfaces into one pinned private base and aggregate required public/private/end-to-end/preservation evidence; include response-policy loader verification.

### Acceptance

- Compatible changes pass published/private-fit checks; genuine violations fail; infrastructure/unknown results remain distinct.
- Stale versions trigger revalidation; hidden tests introduce no unpublished obligation.
- A mismatch patch whose unit checks pass fails whole-task fit; a correct composed patch creates one aggregate candidate diff. An unpublished private expectation is package_defect, not contributor fault.

### Verify

    pnpm test:acceptance -- --suite integration
    pnpm test:runner -- --real

Commands must really run or be recorded unavailable. Implement the relevant meaningful suite if this is its first owner; an empty script is not evidence.

Coordinator finalizes `.execution/handoffs/M7.1.md` and advances eligible successors. Do not assume previous chat history.

### Implement
