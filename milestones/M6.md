# M6: Customer assignment and contributor portal

A selected contributor can reserve, download and submit without private context.

Read `docs/SPEC.md`, `docs/COMPOSITION.md`, `docs/ARCHITECTURE.md` and `docs/SECURITY.md` before implementing. These task cards are additive to their normative requirements. Normal execution requires accepted prerequisite handoffs. Sequential fallback may use checked implementations under START.md, while independent-review gates remain open.

The milestone passes when every task below has evidence and an independent accepted review. Sequential checked implementations alone do not complete the milestone. A mocked or unavailable mandatory runtime does not satisfy a real-runtime gate.

Write scope: `services/private-api/bridge/**`, `services/external-api/tasks/**`, `services/external-api/bridge/**`, `tests/portal/publication/**`. Shared changes require coordinator ownership.

### Implement

- Signed approved envelope delivery with nonce/expiry/replay protection and public positive projections.

## M6.3: Bounded patch intake and atomic budgets

Role: `security_backend`. Prerequisites: M6.2, M5.1.

Write scope: `services/external-api/submissions/**`, `services/private-api/submission-import/**`, `packages/evaluation/patch-validation/**`, `tests/security/submissions/**`. Shared changes require coordinator ownership.

### Implement

- UTF-8 patch parsing, strict portable paths/edit allowlist, digest and reservation validation.
- Idempotency and reservation/lineage/workspace attempt counters, private bounded submission import.
- External DB owns atomic quota/attempt-permit/outbox commit; signed permits authorize idempotent private import and recovery.

### Acceptance

- Traversal, Windows unsafe paths, evaluator/manifest edits, binary/mode/submodule changes and forged bases fail before execution.
- Concurrent identities/versions cannot bypass limits; duplicate idempotency keys create one attempt; no patch executes on the host.
- Crash/replay tests prove no evaluation without a committed permit and no duplicate authoritative attempt across the bridge.
- One bounded patch may edit approved paths across units; authoritative attempt quotas do not reset or multiply by work-unit count.
