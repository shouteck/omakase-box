# M5.4 draft handoff — fixed composition proxy and aggregate attempt verdicts

## Delivered interfaces

- `packages/evaluation/composition/` — `buildAttemptDescriptor(input)` binds all unit/interface/package/submission digests and fixed harness mapping to ONE authorized attempt; deterministic sha256-derived child jobIds; `attemptsConsumed: 1`; `ADAPTER_HARNESS` fixed mapping.
- `services/runner-controller/composition/` — `buildChildJobs(descriptor, harnessDigests, deadline)` → protocol-`JobSchema`-valid children; `aggregateAttemptVerdict(descriptor, evidence)` → trusted fold (passed | failed | unverified with named cause, `missingJobIds`, `attemptsConsumed: 1`).
- `infra/runner/composition/` — `buildProxyProfile`/`classifyProxyRequest`/`sanitizeProxyResponse` (fixed data-plane profile + request classifier + response sanitizer); `validatePolicyData`/`applyPolicyToResponse` (data-only policy + trusted header application); `validateComposedContract`/`evaluateComposedChecks` (strict contract + fixed check evaluation over injected transports); `planComposedStack`/`runComposedJob`/`loopbackHttpClient` (service-stack plan, aggregate budget, ordered cleanup).
- `infra/runner/jobs/harness/supervisor.mjs` — composed harnesses (`frontend/v1`, `backend-api/v1`, `application-policy/v1`, `composed/v1`) dispatch to `runComposedJob` with the staged candidate policy file; contract faults → signed `unverified`; other harnesses still `unsupported_harness`.
- `infra/runner/jobs/guest-provision.yaml` — `/opt/private-task/composition/` layout for the four new modules (root-only, 0644).

## Limitations

- No service launcher or browser adapter is provisioned in the guest: the composed supervisor branch is real and wired but yields `unverified` (recorded `servicesReady: false`) until the dedicated runner exists. Transports are injected; absent transports never pass.
- Aggregate cgroup enforcement, real egress/disposal evidence, fresh-VM public/private separation and renderer/CDP isolation are planned and coded but NOT executed — physical KVM host remains deferred by user decision.
- Independent review unavailable in this sequential session; sequential review gate stays open.
