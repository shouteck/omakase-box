## Delivered component interfaces

- `MemoryAssignmentStore`: explicit human/AI/team descriptive choices; one-time human assignment binding; defensive copies of choice records and projections. A redeemed invitation deadline is not reused as a reservation deadline.
- `MemoryReservationStore`: serialized local acquire, own-resource reads, frozen terms/expiry, revision checks, in_review conflict, changes_required reactivation and latest-attempt closure. Returned terms cannot mutate stored terms or published compensation. Cancellation guards run before mutation and use fixed domain errors.
- `SqlAssignmentStore` / `SqlReservationStore` / `SqlDefectReportStore`: real PostgreSQL component operations. Fixed the published package column binding, missing reserved_at DDL, BEFORE-trigger return value and table-specific trigger field resolution. Assignment locks plus the unique live-reservation index serialize a two-connection race. Reservation acquire checks a non-disabled external account and an unwithdrawn exact task/package binding. Expired live rows are closed before reacquire. Defects are inserted under a reservation lock, derive contributor identity from the trusted caller, enforce actual expiry without a sweep, and bind idempotent retries to the same contributor and content. Own-only defect reads and positive projections replace raw rows. SQL assignment errors use fixed domain faults.
- `installContributorReservationRoutes`: permission source is required for protected operations; absent actors return 401 instead of an empty 200. Owner actors are never coerced into contributors. Task details expose listing projections before reservation, not full requirements/package metadata. Board failures have fixed safe responses; stale-version responses use 409.
- `projectReservationDownload`: refuses invalid/expired/terminal reservations and serves only released, revalidated package bytes and public instruction projections.
- `PortalScreen`: standalone trusted contributor UI for sign-in, board listing, reservation, instructions, SHA-256-verified download and escaped bounded defect reports. The API base defaults to the contributor hostname and cannot point at the private hostname. It performs no model/candidate execution. This screen is NOT mounted in the normal bootstrap yet.
- `AssignmentsScreen`: standalone owner-only explicit-choice form, default-disabled while publicationReady is false. It does not manufacture approval, send invitations, call a model or pay anyone. It is NOT mounted in the normal private-console bootstrap yet.
