# Kitchen inbox

Kitchen-wide lessons and ideas, one line each, ten at most. Only the head chef writes here. Emptied at every kickoff: each line is adopted or dropped. See "Getting better" in docs/box-v4/KITCHEN.md.

- When a review finds a second instance of the same class of flaw, change the design before the next round instead of fixing the instance. R3 spent four review rounds on one safety rule this way.
- A wave that has delivered its finding closes. Follow-up work gets its own brief and is weighed against the roadmap first, not appended to the wave as a correction round.
