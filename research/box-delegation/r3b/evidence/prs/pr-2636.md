# fix: increment inspector port for IPv6 hosts

Commander increments the Node inspector port when spawning an executable subcommand, but the host patterns exclude colons. Bracketed IPv6 hosts therefore bypass the incrementer, and the child tries to use the parent's port.

For example, running `node --inspect=[::1]:19340 tests/fixtures/inspect.js sub` on `develop` prints `Starting inspector on ::1:19340 failed: address already in use`. With this fix, the child starts its inspector on `[::1]:19341`.

Recognise bracketed IPv6 hosts in the existing shared parser, both with an explicit port and with the default port. Add separate regressions for IPv6 hosts with and without an explicit port using the existing executable-subcommand test helper. No dependencies or API changes.
