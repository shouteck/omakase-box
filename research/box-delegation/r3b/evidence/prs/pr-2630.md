## Problem

Executable subcommands already bump the Node inspector port so the child does not collide with the parent. That covers `--inspect` and `--inspect-brk`, but `--inspect-wait` is left as-is.

```
node --inspect-wait app.js cache
```

The child is spawned with the same `--inspect-wait` (port 9229). Node documents `--inspect-wait[=[host:]port]` the same way as `--inspect-brk`; the incrementer should treat it the same.

## Solution

Recognise `--inspect-wait` in `incrementNodeInspectorPort` and rewrite host/port the same way as `--inspect-brk`.

- `--inspect-wait` → `--inspect-wait=127.0.0.1:9230`
- `--inspect-wait=100` → `--inspect-wait=127.0.0.1:101`
