# A cheaper answer about the Box — design, not permission to run

9 October 2026. No repair agent, fork probe, or instrument fix was run in this session.

**Recommendation:** test the next navigation decision from the same reconstructed search context, rather than buying more complete repairs. First require a no-agent native-equivalence check and count the opportunities in the saved corpus. This can give a defensible answer about navigation on those saved situations. It cannot prove a small repair saving or that the Box never hurts. Even this narrower study is not tiny: about **2.7–15.8 million reported tokens** for 256 pairs, with earlier stops possible. If that is too much, retain the zero-token opportunity count and leave agent benefit undecided.

**1. Replayed next decision — recommended.** Show the same recorded conversation twice, changing only the returned search order, then record the next command. Measure how often that command opens a function changed by the reference fix; also record other promoted functions opened. Draw saved situations independently, with replacement and equal task weight, so hundreds of decisions do not masquerade as hundreds of new repositories. Repeat both versions on sixteen situations to measure instability. At 64, 128 and 256 pairs, projected costs are **0.8–4.6m, 1.4–8.4m and 2.7–15.8m**. Conservative detectable improvements with 80% power are **61, 43 and 31 percentage points**; at the final size an interval can rule out an improvement or worsening of **35 points**. These bounds deliberately allow unknown noise. Smaller differences may be detected, but are not promised. Missing access: the installed history-import path must pass a separately approved no-inference check. Reconstructed history lacks the original private reasoning state; the conclusion is about replayed decisions, not resumed repairs.

**2. Three-command continuations from a real checkpoint.** Let each version keep navigating for three commands. Measure commands and returned text until the first correct-function open, counting failure to open as four, and fix-path versus other promoted opens. For the same 256 pairs plus repeats, observed three-command windows imply **8.2–40.3m tokens**, excluding new shared prefixes needed to obtain real checkpoints. A bounded binary “opened within three commands” measure has the same **31-point** conservative detectable difference and **35-point** equivalence margin. It sees recovery and detours that option 1 misses. Exact forks at a pending search are not established: our old live threads were ephemeral, and documented forks interrupt unfinished turns. This option needs proven checkpoint support or an explicitly labelled reconstruction; it is not presently an executable exact-state design.

**3. Complete short repairs, repeated.** Thirty-two task pairs and eight extra same-arm repeat pairs measure solved tasks and capped token use. The six low-effort runs project **4.2–16.1m tokens** for 80 starts; that range does not guarantee unfamiliar tasks will be equally cheap. Recorded spread gives planning scenarios of roughly **10–31% detectable token change**, not calibrated power. A 5% effect would need about **126–999 pairs**, before calibration extras. A small study cannot reliably resolve repair-success differences; its distribution-free guaranteed detectable difference is about **80 points**. New short, unfamiliar tasks and calibrated repeats are needed. Changing to a cheaper model may buy more starts, but no demonstrated access or token saving is assumed, and the answer would apply to that model. Full repair evidence costs much more certainty per useful search moment.

For option 1 the owner can say: **helps** — “On these replayed search situations, ordering made the next command more likely to open a fix function”; **equivalent within the margin** — “Any change on this measure is smaller than 35 percentage points”; **harms** — “Ordering made that next open less likely”; **undecided** — “The interval still permits a meaningful change either way.” A no-room census means “These searches offer little locating to save,” never “the Box has no benefit anywhere.” A 5-point navigation effect requires about **9,560 pairs** under the conservative guarantee, far beyond this cheap design.
