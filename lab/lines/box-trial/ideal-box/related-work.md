# What exists, and what is still unverified

8 October 2026; primary sources, author-reported results. Kind **1**: runtime evidence silently changes ordinary navigation. Kind **2**: runtime facts/reports the agent chooses or receives as extra context. Kind **3**: search without runtime evidence. **P** denotes a plain evidence engine; **M** denotes model-generated analysis as well. All repair experiments also use a model agent.

Questions: **Q1** all search matches, executed functions first/marked; **Q2** executed code in a file; **Q3** ordered route to failure; **Q4** whether a specified function ran. Shared facts do not establish identical delivery or exactness.

**Inference:** reuse native coverage/report adapters and proven navigation ideas before new backends. ADI offers relevant frame navigation but its core is not confirmed licence-ready. DAIRA's semantic reports and SWE-Doctor's diagnoses require models. MIT pgr offers delivery ideas, not a drop-in runtime/all-match wrapper. None of the inspected set verifies Kind 1; that leaves a candidate combination, not a novelty claim. Plain programs and multiple languages already exist; neither alone distinguishes the Box.
