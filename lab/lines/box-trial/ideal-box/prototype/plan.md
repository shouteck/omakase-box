# Failing-test Box prototype plan

9 October 2026. Governing programme: lab/PROGRAMME.md current narrowed prototype. One lab session, no repair agents or live pair. Reuse the fixed thirty Gate 1 tasks, Gate 1b traces and snapshots, and every retained Gate 3b native invocation (243 across twelve tasks). Do not overwrite historical instruments or evidence.

## Contract fixed before checks

A function identity is repository-relative file plus runtime code starting line, validated against one unique parsed definition and code name. Decorator start is part of runtime identity. A file's current bytes must match the trace-source snapshot. Reject missing, stale, ambiguous or unsupported evidence. Ignore module, lambda/comprehension and class-body pseudo-functions rather than crediting an enclosing function without its own call. Attribute a result to the innermost definition, preventing an executed outer function from marking an uncalled nested definition.

Search delivery is a final display adapter. Keep native stdout/stderr/exit and pipeline computation unchanged; only after the ordinary command finishes may complete human source records be stably reordered and marked. Machine output, file-name-only output and ambiguous locations pass through. No instruction is added to agent context. Use the explicit short ASCII badge [ran] (five bytes) for a match in a verified called function, not proof that the matched statement executed. Retain every native record including duplicates, errors and context groups; marks never enter a downstream filter. Gold is read only by the scorer.

## Checks and measures

1. Script checks every retained native invocation against current bytes and exact trace identity; record unknown state rather than recreate certainty. Saved stream checks are post-processing checks, not fresh native execution. Keep stale source digests unmarked.
2. On all thirty snapshots run installed native ripgrep with the previously fixed Gate 1b words, literal case-sensitive whole-source searches. No third-party project code executes on the host. Each query has actual native streams and source receipts. One task without a trace stays unknown, receives ordinary output, never counts as valid runtime evidence.
3. Independently assert byte-record multiplicity, context/separator preservation, exact mark membership, unmarked stale/missing/ambiguous/nested cases and native error/exit behavior. Include direct adapter and full-pipeline fixtures. Compare before/after positions of historical changed functions with exact base identities; record absent targets and unknowns. This is a navigation proxy, not repair quality.
4. Footprint: zero instruction bytes; five bytes per displayed mark; total returned bytes and bytes before first historical target, before/after, all queries including no-target. Potential prefix-reading savings are a proxy, not a reduction in actual total model input: complete output is still returned. Show signed potential saving minus marks; exclude a costly part from the recommended first version. Do not invent actual model token counts from bytes; any character/4 estimate is explicitly a proxy.
5. Facts on request only far enough for one real task: file's called definitions from validated identity, and ordered path from a fresh bounded call/return/exception collector. Old first-seen unique-call order cannot recover call parentage. Select Django 12193 (small, known failing test) for illustration before seeing new answers. Collect in its pinned prepared image, network off, capabilities dropped, memory/process/time caps, no production patch or model. Record helper/receipt hashes and plain/trace elapsed separately. The answer is an illustration, not efficacy evidence.
6. One fresh sceptic reruns a sample of scripted checks, attacks identity/staleness and checks footprint/recommendation. One writer at a time. Fix mandatory faults, preserve failed outputs where relevant.
