Literal-search improvement is not a realistic agent baseline: mechanical words return long streams from source snapshots. Recorded-agent queries already start near the historical patch. No-target queries keep their badge cost and have zero measured prefix saving. “Net” subtracts badge bytes from text preceding the historical target; it does **not** measure actual model input saved, cognition or necessary non-target reading. Both versions still return complete answers; badges strictly add text. Recommend order-only default and omit routine badges unless later justified. No universal navigation or never-worse repair claim.

37 retained invocations have unknown source state; ten unknown environment state (may overlap). 764 captured locations have differing source digests. These provide no mark. Patched test sources/pseudo-functions are excluded when base data cannot validate them. Unsupported/file-only output stays ordinary. Locations are inputs from the prior wrapper, not newly reconstructed trajectories. This is the 243-stream Gate 3b corpus, not every historical search across all thirty tasks.
