# Failing-test Box lab prototype

9 October 2026. Research-only final-display hook; no live-agent integration. [Plan](plan.md), [result](result.md), [owner page](owner-design.md).

From the lab checkout, Python 3.11+ and installed native ripgrep:

```text
python -B lab/lines/box-trial/ideal-box/prototype/check.py
python -B lab/lines/box-trial/ideal-box/prototype/check-display.py
python -B lab/lines/box-trial/ideal-box/prototype/check-fixes.py
python -B lab/lines/box-trial/ideal-box/prototype/measure.py --output=review-sample django__django-12193 sympy__sympy-16597
python -B lab/lines/box-trial/ideal-box/prototype/footprint.py
```

measure.py without selection checks all thirty tasks and all 243 retained Gate 3b native invocations. Writes stay within this instrument. It parses third-party source as data and runs native search, never project code on the host. Patched tests, pseudo-functions, stale/unknown evidence stay unmarked. Gold is read only after evidence construction, by scoring.

adapter.py validates exact file/code-start/name identities, selects the innermost definition and stably reorders complete human source records/context groups. Marks indicate called-function membership, not line execution. Saved queries use prior captured locations/digests; re-annotation is post-processing, not fresh native replay.

display.complete runs the ordinary command, checks current file hashes, then presents it. Order-only is default: no badge/instruction bytes. Optional [ran] adds five bytes per mark. Native stderr/exit pass through. Pipelines must finish natively before this hook; marks/reordering never feed filters. Canonical source/line formats are recognized; other paths/formats fall back. This is a candidate command-completion integration point, not a replacement agent command.

facts.py uses only the pinned Django 12193 image, checks the kitchen, applies only the test overlay, runs plain/ordered phases with 60-second caps, saves receipts and removes its own container/newly pulled image. Third-party code executes only there, network off and capabilities dropped. collector.py keeps all repository calls and local ordered events only under the named test; no model or values. External-library frames/child processes are not a complete path. One illustration, not efficacy evidence.

recheck.py re-presents all 587 original literal streams and all 243 retained invocations with the corrected guards. It verifies input hashes, retains original receipts and native timings, and records current instrument hashes; it does not re-execute native searches. Multiline output passes through intact. Captured paths must agree with an explicit native filename; number-only output requires one explicit source file.

Raw streams/source-bearing facts remain ignored with receipt hashes. Scratch contains owned source data/fixtures and is disposable after review. Failed fixture assumptions, initial collector and full-dictionary comparison are preserved in development-correction.json and named before-correction files. Historical gate files remain untouched.
