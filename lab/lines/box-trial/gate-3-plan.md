## Search tool and scoring

`box-search` accepts a pattern, optional literal/case-insensitive switches and optional path filters. It returns ordinary path:line:text matches, in lexical path then source-line order, from the narrow executed function spans only, with no ranking hints or real-fix seeds. Searches inspect base executed spans; this frozen base index is disclosed in tool help. It is not a list to read and never appears in context unless the agent calls the command. Search results, no-match and invalid-pattern responses are all calls. Tool checks use authored fixtures to compare ordinary search results restricted to known spans, including no matches and text outside executed functions. Index bytes remain out of initial context. Baseline spans can become stale after edits; report that limitation and whether searches occur after edits.

Score in a fresh independent container at the pinned original base with the benchmark test patch and the candidate production patch. Restore/protect benchmark tests; candidate changes to the benchmark's test files cannot establish success. Run all FAIL_TO_PASS and PASS_TO_PASS tests, requiring each requested failing test to pass and every guard to pass; timeout, missing results or setup failures are unknown, never a success. Preserve every start, raw command/model event, usage, candidate diff/hash and evaluator receipt, even failures. Gold production patches are consulted only by post-run reading metrics; not by agents, task/tool construction or success grading.

## Decision fixed before results

Run twelve pairs. Primary: paired official-test success differences, gains and losses; exact two-sided McNemar/binomial test on discordant pairs. "More right beyond noise" requires no solved task lost and p<0.05 (with twelve pairs at least six gains and zero losses). Always show all pairs rather than collapse missing outcomes into failures. Cost route: among tasks both solve, require at least six comparable pairs, median token reduction at least 20%, exact paired sign-test p<0.05, and no median increase in steps or agent wall time. Report raw/token-cached/time spreads; token totals are usage, not dollar invoices. These thresholds operationalize a large detectable change for this tiny exploratory sample; smaller true effects remain undecidable.

If twelve pairs show no success gain and neither median token reduction of 20% nor a cost sign-test signal, or Box has losses and no gains, stop without repeats. Otherwise run the fixed three tasks twice more per arm (36 attempts maximum); report per-task spread and whether direction survives repeats. Never choose repeats by favorable outcomes. No-harm check: report four easy pairs separately; absent an initial listing, allowance is the measured extra instruction line and actual command schema, not hundreds of prepaid Box-content tokens. If observed Box-only costs exceed that allowance, the strict no-harm condition has not been demonstrated. Missing accounting cannot prove cost/no-harm. A stronger model's Gate 2 outcomes are context only; this selected sample is not a solve rate estimate.

Record whether the agent called Box, frequency, match volume, before/after first edit, and use in each solved-in-one-arm case. First reaching and text between reaching/editing reuse Gate 2's qualified source-span mapper; report classifier blind spots, token amplification and wide views. No inference that outside-Box reading is waste.

One fresh sceptic reruns selection, tool fixture checks and scoring from saved receipts; reads discordant cases without rerunning agents. Report one table and one sentence. Stop after this Gate 3 session; Gate 1c, new techniques and product transfer are separate decisions.
