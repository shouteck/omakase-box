## Title

Remove unused chai dependency from CJS module tests

## Body

## Summary

`tests/module/cjs/package.json` declares `chai` as a development dependency, but the CJS module tests use Node.js built-in `assert` and do not import `chai`.

## History

The CJS module test package and its `chai` dependency were added in #7510. The tests introduced in that change already used `assert`; I found no `chai` imports in this package at that point or later.

## Proposed change

Please remove `chai` from `tests/module/cjs/package.json` and update `tests/module/cjs/package-lock.json`. Keep the separate `chai` dependency in `tests/smoke/cjs`, where the smoke tests still use it.

The contribution guidelines reserve dependency-only PRs for maintainers and approved bots, so I am opening an issue instead of a PR.
