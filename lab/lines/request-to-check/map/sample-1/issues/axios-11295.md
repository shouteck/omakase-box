## Title

formToJSON throws for nested fields named length

## Body

### Describe the bug

Converting a FormData with a normal nested field named `length` throws `RangeError: Invalid array length`. This affects `axios.formToJSON()` and posting FormData with `Content-Type: application/json`.

### To reproduce

```js
import axios from 'axios';

const form = new FormData();
form.append('metadata[length]', 'long');
console.log(axios.formToJSON(form));
```

Actual: `RangeError: Invalid array length`.

Expected: `{ metadata: { length: 'long' } }`.

The dot form `metadata.length`, repeated `metadata[length]` values and `metadata[length][unit]` also fail. These names can come directly from ordinary HTML form inputs.

### Environment

Axios `v1.x` at `6576f5753e26444d8d04b0a7c0b4d9d0a83bdaa0`, Node 22.22.1 and Linux. The issue is in the shared FormData-to-JSON parser: an intermediate array receives the named `length` key before it can be converted to an object. A focused fix can convert that intermediate array before descending into `length` while preserving any numeric siblings.

AI assistance was used to investigate this report.
