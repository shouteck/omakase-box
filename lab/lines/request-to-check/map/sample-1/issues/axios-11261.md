## Summary

The root `package.json` still lists `chalk` as a development dependency, but no current root scripts or tests import it.

## History

- `chalk` was added in #5453 for the old contributor/PR generation helpers.
- The remaining root uses, including `bin/helpers/colorize.js` and `bin/run-karma-tests.js`, were removed in #10584. The dependency declaration was left behind.

## Proposed change

Please remove the root `chalk` development dependency from `package.json` and update the root `package-lock.json`. This should not affect the public API or runtime behavior.

The contribution guidelines reserve dependency-only PRs for maintainers and approved bots, so I am opening an issue instead of a PR.
