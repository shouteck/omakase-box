## Title

Inconsistent handling of primitive request bodies across adapters (silent drop vs ERR_BAD_REQUEST)

## Body

## Describe the issue

Passing primitive values (numbers, booleans) as the request body produces conflicting and inconsistent behavior across the three default adapters (`http`, `xhr`, and `fetch`):

1. **Falsy primitives (`0`, `false`)**:
   - `fetch`: coerces to string and sends `"0"` / `"false"`.
   - `xhr`: evaluates `requestData || null` in `lib/adapters/xhr.js:275`, coercing `0`/`false` to `null` and sending an **empty body**.
   - `http`: evaluates `data && req.write(data)` in `lib/adapters/http.js:1597`, skipping `req.write()` and sending an **empty body**.

2. **Truthy primitives (`123`, `true`)**:
   - `fetch`: coerces to string and sends `"123"` / `"true"`.
   - `xhr`: evaluates `123 || null` -> `123`, which browser XHR WebIDL stringifies and sends (`"123"` / `"true"`).
   - `http`: enters validation `else if (data && !utils.isStream(data))` in `lib/adapters/http.js:955`, which only permits `Buffer`, `ArrayBuffer`, or `string`, throwing an immediate rejection:
     `ERR_BAD_REQUEST: Data after transformation must be a string, an ArrayBuffer, a Buffer, or a Stream`.

### Summary Matrix

| Primitive Value | `fetch` adapter | `xhr` adapter | `http` adapter |
| :--- | :--- | :--- | :--- |
| `0` | Sends `"0"` (length 1) | Sends `""` (silent drop) | Sends `""` (silent drop) |
| `false` | Sends `"false"` (length 5) | Sends `""` (silent drop) | Sends `""` (silent drop) |
| `123` | Sends `"123"` (length 3) | Sends `"123"` (coerced) | Throws `ERR_BAD_REQUEST` |
| `true` | Sends `"true"` (length 4) | Sends `"true"` (coerced) | Throws `ERR_BAD_REQUEST` |

## Example code

```js
import http from 'node:http';
import axios from 'axios';

const server = http.createServer((req, res) => {
  let body = '';
  req.on('data', (chunk) => (body += chunk));
  req.on('end', () => {
    res.writeHead(200, { 'Content-Type': 'application/json' });
    res.end(JSON.stringify({ receivedBody: body, length: req.headers['content-length'] }));
  });
}).listen(0, async () => {
  const url = `http://127.0.0.1:${server.address().port}`;

  // 1. Falsy number:
  const resFetchZero = await axios.post(url, 0, { adapter: 'fetch' });
  console.log('fetch (0):', resFetchZero.data); // { receivedBody: '0', length: '1' }

  const resHttpZero = await axios.post(url, 0, { adapter: 'http' });
  console.log('http (0):', resHttpZero.data);   // { receivedBody: '', length: '0' } (silently dropped)

  // 2. Truthy number:
  const resFetchNum = await axios.post(url, 123, { adapter: 'fetch' });
  console.log('fetch (123):', resFetchNum.data); // { receivedBody: '123', length: '3' }

  try {
    await axios.post(url, 123, { adapter: 'http' });
  } catch (err) {
    console.log('http (123):', err.code, err.message);
    // ERR_BAD_REQUEST: Data after transformation must be a string, an ArrayBuffer, a Buffer, or a Stream
  }

  server.close();
});
