## Reading limits

S1, S3 and S5 have weaker access than the other foundations. No source here establishes how frequently a useful small Box includes a real repair. No novelty claim is supported by this search. The first replay should compare simple explicit rules before adopting a complex slicer. Formal adoption would require reading the exact tool/version's semantic assumptions, including exceptions, native functions, reflection, module loading and runtime restrictions. Reflection and generated code are not collectively solved by an import graph.
