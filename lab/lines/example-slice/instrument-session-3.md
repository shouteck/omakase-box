## Prior predictions and checks

- The task collector rejects any confirmation ID before making a network request, and refuses to overwrite an existing development snapshot.
- For frozen development IDs only, it records accepted-commit provenance and changed **test-family** content; neither production patches nor changed production path names are emitted. Dev content may be inspected under the protocol, but confirmation remains closed. Fields omitted by the GitHub API are unknown, not inferred.
- On known-answer fixtures, E seeds only supplied executed production files; EI traverses local imports from those seeds; R also traverses unexecuted test helpers; G contains every production file under the registered root. Dynamic/missing/external edges remain explicit.
- An included generated source file and an out-of-root sibling count in repository disclosure; tests do not count in the source denominator. Root and repository denominators stay separate; a zero denominator is unknown.
- A stable different failure, unknown context, immutable-file edit, forbidden new path, or production expansion cannot pass the primary screen. Historical containment is checked separately from reproduction.
- Path traversal, absolute paths, symlink records, case-colliding paths and nonfinite byte counts fail closed, not silently trimmed.
